# BioMed Hub Library

Drop PDFs here in subject-coded folders, then list them in `manifest.json`.

```
library/
  manifest.json
  U21BM301/
    anatomy-unit1.pdf
    anatomy-unit2.pdf
  U21BM302/
    instrumentation-2024-regular.pdf
```

Easiest path: open the site, go to `#/admin`, fill the form, copy the JSON snippet it generates, paste into `manifest.json`. Commit + push. Done.
